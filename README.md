# Melvor Idle 2 简体中文一键补丁

非官方粉丝汉化。适用于 Steam 正式抢先体验版 **Melvor Idle 2: A RuneScape Adventure**（AppID **3218350**，build **26724394**，Windows x64）。

本补丁改写 `Melvor2.exe` 内嵌语言包 **`Locale/en_GB.po`**（当前版本只会加载这一份），因此游戏里请选择 **English / en_GB**。官方虽附带 `zh_CN.po`，但本 build 未把它列入已加载翻译。修改后 **数字签名会失效**。不改 DLL、存档和数值，也不会自动启动游戏。不需要安装 Python，使用 Windows 自带的 PowerShell 即可。

当前目录共 13052 个条目（1952 个复数）。译文以官方 `zh_CN.po` 为主，合并了 Demo 可用译文，并补全了物品名称在无上下文时的回退，以及效果名「过度生长」等前后用词统一。

## 怎么用

1. 下载本仓库中的 [`Melvor2_简体中文_build26724394.zip`](Melvor2_简体中文_build26724394.zip)，或直接使用仓库里的文件夹。
2. 把 `Melvor2_简体中文` 文件夹放到游戏目录，与 `Melvor2.exe` **同一层**。
3. **完全退出游戏**（任务管理器里确认没有 Melvor2）。
4. 双击 **`一键汉化.cmd`**。窗口会显示进度，大约 2–3 分钟，请勿中途关闭。
5. 看到成功后再从 Steam 启动游戏，语言选 **English / en_GB**。
6. 要还原官方英文版：退出游戏后双击 **`取消汉化.cmd`**。

版本不符，或使用 Steam「验证游戏文件」后，会恢复官方 EXE，需要重新运行一键汉化。`backups/` 由脚本自动生成，请勿在安装或还原中途删除。

若备份被删：只要 `Melvor2.exe` 仍是本包已安装的版本，再运行一键汉化即可识别。取消汉化需要官方 EXE 备份；没有备份时，请先用 Steam 验证游戏文件，再重新一键汉化。

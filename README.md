# Melvor Idle 2 简体中文一键补丁

非官方粉丝汉化。适用于 Steam 正式抢先体验版 **Melvor Idle 2: A RuneScape Adventure**（AppID **3218350**，**v0.11.7-alpha**，build **26886380**，Windows x64）。

本补丁改写 `Melvor2.exe` 内嵌的 **`Locale/en_GB.po`**（当前版本只会加载这一份），因此游戏里请选择 **English / en_GB**。官方虽附带 `zh_CN.po`，但本 build 未把它列入已加载翻译。为了让部分直接读取原文、以及关闭自动翻译的实时数字标签也能显示中文，本补丁还会写入 `MelvorBase.json` 和 38 个界面模板。修改后 **数字签名会失效**。不改 DLL、存档和数值，也不会自动启动游戏。不需要安装 Python，使用 Windows 自带的 PowerShell 即可。

当前语言包共 14199 个条目（1970 个复数）。译文以官方 `zh_CN.po` 为主，合并了 Demo 可用译文，并补全了物品名称、界面标签、技能指南、任务对话，以及工具带装备条件等游戏实际查找的原文。同时修正了官方语言包里「撬锁器」「柠檬」「柠檬宝箱」「蒙面头套」等误译，并统一了「过度生长」「未充能法球」等用词。此前已统一的译名和补译均予以保留。

本次更新面向 v0.11.7-alpha（build 26886380），从该版本官方 EXE 重新打包。新增译文包括游戏内新闻面板、银行标签图标、套装加成、物品属性和未满足条件等新设置、灵巧印记商店按技能拆开的分类名，以及采矿日志相关描述。

## 怎么用

1. 下载本仓库中的 [`Melvor2_简体中文_build26886380.zip`](Melvor2_简体中文_build26886380.zip)，或直接使用仓库里的文件夹。
2. 把 `Melvor2_简体中文` 文件夹放到游戏目录，与 `Melvor2.exe` **同一层**。
3. **完全退出游戏**（任务管理器里确认没有 Melvor2）。
4. 双击 **`一键汉化.cmd`**。窗口会显示进度，大约 2–3 分钟，请勿中途关闭。
5. 看到成功后再从 Steam 启动游戏，语言选 **English / en_GB**。
6. 要还原官方英文版：退出游戏后双击 **`取消汉化.cmd`**。

版本不符，或使用 Steam「验证游戏文件」后，会恢复官方 EXE，需要重新运行一键汉化。`backups/` 由脚本自动生成，请勿在安装或还原中途删除。

若备份被删：只要 `Melvor2.exe` 仍是本包已安装的版本，再运行一键汉化即可识别。取消汉化需要官方 EXE 备份；没有备份时，请先用 Steam 验证游戏文件，再重新一键汉化。

## 校验

补丁包文件名：`Melvor2_简体中文_build26886380.zip`。GitHub Release 中的 `Melvor2_zh-CN_build26886380.zip` 是同一份文件（仅文件名改为英文，方便下载）。SHA256 见仓库里的 `Melvor2_简体中文_build26886380.zip.sha256.txt`。

本包必须安装到官方 `Melvor2.exe`（SHA256 `4fbd4504809b2d2cf3c12ad962a632f4b1dd0934eebd2452f3766ebc313146d1`，602,186,032 字节）。若 Steam 更新或验证游戏文件后哈希不一致，请勿强行安装。

若脚本报错，把窗口里的红色失败信息发出来即可排查。

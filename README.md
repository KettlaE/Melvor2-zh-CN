# Melvor Idle 2 简体中文一键补丁

非官方粉丝汉化。适用于 Steam 正式抢先体验版 **Melvor Idle 2: A RuneScape Adventure**（AppID **3218350**，build **26724394**，Windows x64）。

本补丁改写 `Melvor2.exe` 内嵌的 **`Locale/en_GB.po`**（当前版本只会加载这一份），因此游戏里请选择 **English / en_GB**。官方虽附带 `zh_CN.po`，但本 build 未把它列入已加载翻译。为了让部分直接读取原文、以及关闭自动翻译的实时数字标签也能显示中文，本补丁还会写入 `MelvorBase.json` 和 38 个界面模板。修改后 **数字签名会失效**。不改 DLL、存档和数值，也不会自动启动游戏。不需要安装 Python，使用 Windows 自带的 PowerShell 即可。

当前语言包共 14058 个条目（1968 个复数）。译文以官方 `zh_CN.po` 为主，合并了 Demo 可用译文，并补全了物品名称、界面标签、技能指南、任务对话，以及工具带装备条件等游戏实际查找的原文。同时修正了官方语言包里「撬锁器」「柠檬」「柠檬宝箱」「蒙面头套」等误译，并统一了「过度生长」「未充能法球」等用词。

本次更新还补回了长文本换行，把地名统一为「月牙湖」，战斗属性 Ward / Armour 分别译为「结界」「护甲 / 护甲值」（装备名与锻造子类仍用「盔甲」），合金 Ironsteel 统一为「钢铁」，制作相关的 Output / Input 分别改为「产出」「投入」，种植田地的 Clear 按钮改为「清空」（天气 Clear 仍为「晴天」），力量精通称号 Warrior 改为「勇士」。另外将攻击距离 Long-Range 译为「长距」，升级提示改为「{0}个新里程碑！」，毛皮材料分别译为「兔皮」「狼皮」「暗影狐皮」，Sushi Base 译为「寿司底」，物品与被动 Stinger 统一为「螫针」，Dragonbone Offhand Glaive 译为「龙骨副手战刃」，捕网 Basic / Reinforced / Fortified / Moonscale Net 分别译为「基础 / 加固 / 强化 / 月鳞捕网」，without failing 译为「无失败捕获」，Best Trap 译为「最佳捕获」，战斗任务动词 Slay 译为「击杀」（技能「屠杀者」及相关界面不变），Aurora 译为「极光」。

## 怎么用

1. 下载本仓库中的 [`Melvor2_简体中文_build26724394.zip`](Melvor2_简体中文_build26724394.zip)，或直接使用仓库里的文件夹。
2. 把 `Melvor2_简体中文` 文件夹放到游戏目录，与 `Melvor2.exe` **同一层**。
3. **完全退出游戏**（任务管理器里确认没有 Melvor2）。
4. 双击 **`一键汉化.cmd`**。窗口会显示进度，大约 2–3 分钟，请勿中途关闭。
5. 看到成功后再从 Steam 启动游戏，语言选 **English / en_GB**。
6. 要还原官方英文版：退出游戏后双击 **`取消汉化.cmd`**。

版本不符，或使用 Steam「验证游戏文件」后，会恢复官方 EXE，需要重新运行一键汉化。`backups/` 由脚本自动生成，请勿在安装或还原中途删除。

若备份被删：只要 `Melvor2.exe` 仍是本包已安装的版本，再运行一键汉化即可识别。取消汉化需要官方 EXE 备份；没有备份时，请先用 Steam 验证游戏文件，再重新一键汉化。

## 校验

补丁包文件名：`Melvor2_简体中文_build26724394.zip`。GitHub Release 中的 `Melvor2_zh-CN_build26724394.zip` 是同一份文件（仅文件名改为英文，方便下载）。SHA256 见仓库里的 `Melvor2_简体中文_build26724394.zip.sha256.txt`。

若脚本报错，把窗口里的红色失败信息发出来即可排查。
